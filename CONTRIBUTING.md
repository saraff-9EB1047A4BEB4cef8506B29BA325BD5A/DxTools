# Участие в DxTools

## Лицензия вклада

Проект распространяется по GNU GPL v2 (`GPL-2.0-only`). Отправляя pull
request, вы подтверждаете, что вправе передать этот код, и соглашаетесь
лицензировать его на условиях GPLv2. Отдельный CLA не требуется.

Каждый коммит должен содержать sign-off:

```powershell
git commit -s -m "краткое описание"
```

Подпись означает согласие с Developer Certificate of Origin 1.1
(<https://developercertificate.org/>).

## Что принимается

- исправления багов и регрессий;
- новые функции, соответствующие [spec.md](spec.md);
- тесты, документация, переводы.

## Чего не принимаем

- код и ресурсы, несовместимые с GPLv2 (например, Apache-2.0);
- проверки лицензий, DRM и ограничения функций в коде программы:
  коммерческая модель построена на поддержке
  ([docs/commercial.md](docs/commercial.md)), а не на блокировках;
- телеметрию и сетевые вызовы без явного согласия пользователя;
- инъекции в чужие процессы (spec.md §3.1).

## Сборка и проверки

```powershell
dotnet build DxTools.sln -c Release
dotnet test DxTools.sln -c Release
```

Нативная библиотека и MSI собираются через `build/build.ps1`, требования
перечислены в README. Pull request должен собираться без новых
предупреждений и проходить все тесты.

## Стиль

- следуйте `.editorconfig` и стилю соседнего кода;
- комментарии и идентификаторы — по правилам проекта, без лишних
  комментариев;
- новые пользовательские строки добавляйте в оба языка (русский и
  английский);
- новые WPF-контролы стилизуйте в `src/DxTools.App/Themes/Controls.xaml`.

## Бренд

Форки и производные сборки не могут использовать имя и логотип DxTools.
Подробности — в [TRADEMARK.md](TRADEMARK.md).

## Коммерческие запросы

Вопросы о Pro Support, счетах и договорах — по контакту из
[docs/commercial.md](docs/commercial.md), не через Issues.
