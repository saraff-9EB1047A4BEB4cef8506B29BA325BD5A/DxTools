# DxTools — руководство пользователя

Версия документа: 0.2 (Phase 1)
Применимо к: DxTools 0.2.0-alpha, Windows 11 22H2+

## 1. Установка

1. Запустите `DxTools-0.2.0-x64.msi`.
2. Примите условия GNU GPL v2 в лицензионном диалоге.
3. Подтвердите запрос UAC: установка выполняется в `Program Files\DxTools`
   для всех пользователей компьютера.
4. Дождитесь завершения и нажмите «Готово».

Тихая установка:

```powershell
msiexec /i DxTools-0.2.0-x64.msi /qn /l*v install.log
```

Удаление: «Параметры → Приложения → Установленные приложения → DxTools».
Пользовательские настройки в `%AppData%\DxTools` при удалении сохраняются.

## 2. Первый запуск

Приложение запускается из меню «Пуск» и работает в системном трее.
Двойной щелчок по значку открывает настройки. Закрытие окна скрывает его
в трей; приложение продолжает работать.

## 3. Общие настройки

- **Запускать при входе в Windows** — добавляет приложение в автозапуск
  текущего пользователя (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- **Запускать свёрнутым** — при автозапуске окно не показывается.
- **Язык** — русский, английский или автоматически. Смена языка применяется
  после перезапуска приложения.
- **Тема** — системная, светлая или тёмная. Применяется сразу.

### Резервная копия

- **Экспорт** — сохраняет `settings.json`, профили дисплеев и конфигурацию
  обоев в ZIP-файл.
- **Импорт** — восстанавливает данные из ZIP. После импорта перезапустите
  DxTools; текущая сессия не перезаписывает импортированные файлы.

## 4. Мониторы

Вкладка «Мониторы» показывает текущую конфигурацию: имя, разрешение, позицию,
DPI и частоту обновления.

### Сохранение профиля

1. Нажмите «Сохранить текущую конфигурацию».
2. При необходимости введите имя; пустое имя получит автоматическое.
3. Включите «Применять при подключении», если профиль должен автоматически
   применяться, когда подключён тот же набор мониторов.

### Применение профиля

1. Нажмите «Применить» у сохранённого профиля.
2. Экран может кратковременно измениться.
3. В течение 15 секунд подтвердите настройки кнопкой «Оставить».
   Если не подтвердить или нажать «Вернуть», DxTools восстановит предыдущую
   конфигурацию.

При ошибке применения DxTools автоматически пытается вернуть предыдущее
состояние.

### Удаление профиля

Нажмите «Удалить» рядом с профилем. Файл профилей:
`%AppData%\DxTools\display-profiles.json`.

## 5. Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+Left` | переместить активное окно на предыдущий монитор |
| `Ctrl+Alt+Right` | переместить активное окно на следующий монитор |
| `Ctrl+Alt+Up` | включить/выключить «поверх всех окон» |

Перенос сохраняет относительное положение окна и учитывает DPI монитора.
Свернутые и развёрнутые окна обрабатываются отдельно.

Если сочетание занято другим приложением, DxTools покажет его как
«Недоступна» на вкладке «Горячие клавиши». Настраиваемый редактор сочетаний
появится в Phase 2.

## 6. Обои

Вкладка «Обои» задаёт изображение для каждого монитора.

1. Нажмите «Выбрать изображение» у нужного монитора.
2. Выберите PNG, JPG, JPEG или BMP.
3. Повторите для остальных мониторов.
4. Выберите режим: «Заполнить», «Вписать», «Растянуть», «По центру»
   или «Замостить».
5. Нажмите «Применить обои».

DxTools создаёт композитное изображение размером с виртуальный рабочий стол
и устанавливает его в режиме span. Файлы композита находятся в
`%LocalAppData%\DxTools\wallpaper`. Старые композиты автоматически удаляются.

Если для монитора не выбрано изображение, его область будет чёрной.

## 7. Диагностика

- **Состояние native-библиотеки** — версия API, версия библиотеки и результат
  проверки связи.
- **Открыть папку логов** — `%LocalAppData%\DxTools\logs`.
- **Выполнить самопроверку** — повторно проверяет native-библиотеку.

## 8. Трей

Меню значка:

- **Открыть DxTools** — показать окно настроек;
- **Состояние** — краткая информация о native-модуле;
- **О программе** — версия и лицензия;
- **Выход** — завершить приложение.

## 9. Безопасный режим

Если приложение работает нестабильно, запустите:

```powershell
DxTools.exe --safe-mode
```

В безопасном режиме отключаются нативные проверки, горячие клавиши и
авто-применение профилей. Настройки, логи и просмотр конфигурации работают.

## 10. Командная строка

| Параметр | Действие |
|---|---|
| `--autostart` | запуск при входе в систему, окно скрыто |
| `--safe-mode` | безопасный режим |
| `--show` | показать окно в уже запущенном экземпляре |
| `--version` | показать версию |
| `--help` | краткая справка |

## 11. Логи

Логи находятся в `%LocalAppData%\DxTools\logs\DxTools-YYYYMMDD.log`.
При аварийном завершении приложение показывает путь к логу. Перед отправкой
отчёта об ошибке приложите последний файл лога.

## 12. Известные ограничения 0.2.0-alpha

- слайдшоу обоев из папки и настройка интервала ещё не реализованы;
- горячие клавиши фиксированы; редактор — Phase 2;
- панель задач, titlebar-кнопки, сплиты и профили позиций окон — Phase 2;
- развёртывание окна на несколько мониторов и прозрачность окон — Phase 2;
- изменение DPI scaling через профиль не поддерживается;
- elevated-приложения (запущенные от администратора) могут не перемещаться
  без UIAccess; модуль появится в Phase 3;
- нет автоматического обновления;
- установщик не подписан; SmartScreen может показать предупреждение;
- ARM64 не поддерживается.

## 13. Удаление

«Параметры → Приложения → Установленные приложения → DxTools → Удалить».
Чтобы удалить и настройки, после удаления удалите папки:

```
%AppData%\DxTools
%LocalAppData%\DxTools
```
