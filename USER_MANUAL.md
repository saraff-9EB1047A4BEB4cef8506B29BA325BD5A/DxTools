# DxTools — руководство пользователя

Версия документа: 0.14 (Phase 3A)
Применимо к: DxTools 0.11.0-alpha, Windows 11 22H2+

## 1. Установка

1. Запустите `DxTools-0.11.0-x64.msi`.
2. Примите условия GNU GPL v2 в лицензионном диалоге.
3. Подтвердите запрос UAC: установка выполняется в `Program Files\DxTools`
   для всех пользователей компьютера.
4. Дождитесь завершения и нажмите «Готово».

Тихая установка:

```powershell
msiexec /i DxTools-0.11.0-x64.msi /qn /l*v install.log
```

Удаление: «Параметры → Приложения → Установленные приложения → DxTools».
Пользовательские настройки в `%AppData%\DxTools` при удалении сохраняются.

## 2. Первый запуск

Приложение запускается из меню «Пуск» и работает в системном трее.
Двойной щелчок по значку открывает настройки. Закрытие окна скрывает его
в трей; приложение продолжает работать.

## 3. Общие настройки

- **Запускать при входе в Windows** — добавляет приложение в автозапуск
  текущего пользователя (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- **Запускать свёрнутым** — при автозапуске окно не показывается.
- **Панель задач на дополнительных мониторах** — включает панель задач DxTools
  на всех неосновных мониторах и заменяет панель задач Windows на них.
- **Автоскрытие панели задач** — скрывает панель, когда курсор уходит с неё;
  для показа подведите курсор к нижнему краю монитора.
- **Язык** — русский, английский или автоматически. Смена языка применяется
  после перезапуска приложения.
- **Тема** — системная, светлая или тёмная. Применяется сразу.

### Закреплённые приложения

- **Добавить приложение** — выбрать `.exe`; кнопка появится на каждой
  панели задач DxTools.
- **Удалить** — убрать приложение из закреплённых.

Если приложение уже запущено, на панели показывается его группа окон;
закреплённая кнопка не дублируется.

### Кнопки в заголовке окон

Включите «Кнопки в заголовке окон», чтобы на активном окне появлялись две
кнопки: «→» — перенести окно на следующий монитор, «T» — включить/выключить
«поверх всех окон». Кнопки работают без инъекций в процесс приложения.

Поддерживаются окна со стандартным заголовком; для полноэкранных и
нестандартных окон кнопки скрываются.

### Резервная копия

- **Экспорт** — сохраняет `settings.json`, профили дисплеев и конфигурацию
  обоев в ZIP-файл.
- **Импорт** — восстанавливает данные из ZIP. После импорта перезапустите
  DxTools; текущая сессия не перезаписывает импортированные файлы.

## 4. Мониторы

Вкладка «Мониторы» показывает текущую конфигурацию: имя, разрешение, позицию,
DPI и частоту обновления.

### Сохранение профиля

1. Нажмите «Сохранить текущую конфигурацию».
2. При необходимости введите имя; пустое имя получит автоматическое.
3. Включите «Применять при подключении», если профиль должен автоматически
   применяться, когда подключён тот же набор мониторов.

### Применение профиля

1. Нажмите «Применить» у сохранённого профиля.
2. Экран может кратковременно измениться.
3. В течение 15 секунд подтвердите настройки кнопкой «Оставить».
   Если не подтвердить или нажать «Вернуть», DxTools восстановит предыдущую
   конфигурацию.

При ошибке применения DxTools автоматически пытается вернуть предыдущее
состояние.

### Удаление профиля

Нажмите «Удалить» рядом с профилем. Файл профилей:
`%AppData%\DxTools\display-profiles.json`.

### Сплиты монитора

На вкладке «Мониторы» задайте число строк и колонок (1–3). Сетка применяется
к текущему монитору активного окна. Сочетания `Ctrl+Alt+1..4` прикрепляют
окно к первым четырём ячейкам.

Включите «Панель задач на каждый сплит», чтобы внизу каждой ячейки появилась
отдельная overlay-панель задач с окнами этой ячейки. Такие панели не
резервируют рабочую область и могут перекрывать нижнюю часть окон ячейки.

### Иконки рабочего стола

Вкладка «Рабочий стол» сохраняет и восстанавливает позиции иконок.

1. Нажмите «Сохранить позиции иконок».
2. Введите имя профиля при необходимости.
3. Для восстановления нажмите «Применить» у профиля.

Сопоставление выполняется по индексу иконки; порядок иконок должен
оставаться неизменным. Для позиционирования используется доступ к списку
иконок Explorer. Автоматическое упорядочивание Windows может изменить
результат.

## 5. Профили окон

Вкладка «Окна» сохраняет и восстанавливает позиции открытых окон.

1. Нажмите «Сохранить позиции окон».
2. При необходимости введите имя профиля.
3. Для восстановления нажмите «Применить» у профиля.

Сопоставление выполняется по пути исполняемого файла и заголовку окна;
если заголовок изменился, используется первое окно этого приложения.
Развёрнутые окна восстанавливаются развёрнутыми. Профиль применяется только
к уже открытым окнам.

Файл: `%AppData%\DxTools\window-profiles.json`.

## 6. Панель задач на дополнительных мониторах

При включённой настройке DxTools создаёт панель задач внизу каждого
неосновного монитора.

- **Dx** — открыть настройки DxTools.
- **Кнопка приложения** — активировать окно; если у приложения несколько окон,
  щелчок переключает их по кругу. Активное окно сворачивается повторным
  щелчком.
- **Счётчик** — число окон в группе отображается как `(N)`.
- **Наведение** — показывает live-превью активного окна группы через DWM.
- **Колесо мыши** — горизонтальная прокрутка списка.
- **Часы** — текущее время.
- **▾** — открывает зеркало системного трея: иконки уведомлений
  Windows с подсказками; щелчок передаёт действие исходному значку.

Панель задач использует AppBar и резервирует место рабочего стола, поэтому
развёрнутые окна не перекрывают её. Если на дополнительном мониторе уже
показана панель задач Windows, DxTools временно скрывает её и занимает её
место; при штатном выходе из DxTools панель задач Windows возвращается.

Чтобы вернуть стандартную панель задач Windows, отключите настройку
«Панель задач на дополнительных мониторах» или выйдите из DxTools.

При запуске fullscreen-приложения на этом мониторе панель автоматически
скрывается и возвращается после выхода из него.

При включённом автоскрытии панель убирается, когда курсор покидает её.
Подведите курсор к нижнему краю монитора, чтобы показать панель. При
использовании AppBar рабочая область расширяется на время скрытия.

Закреплённые приложения добавляются в разделе «Общие» и отображаются на
каждой панели DxTools.

Ограничения текущей версии: нет системного трея, DWM live-превью и
автоскрытия. Панель задач создаётся только для неосновных мониторов;
панель задач Windows на основном мониторе не изменяется.

## 7. Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+Left` | переместить активное окно на предыдущий монитор |
| `Ctrl+Alt+Right` | переместить активное окно на следующий монитор |
| `Ctrl+Alt+Up` | включить/выключить «поверх всех окон» |
| `Ctrl+Alt+1..4` | прикрепить окно к сплиту 1–4 |

Перенос сохраняет относительное положение окна и учитывает DPI монитора.
Свернутые и развёрнутые окна обрабатываются отдельно.

Нажмите «Изменить» на вкладке «Горячие клавиши», затем нажмите новое
сочетание с Ctrl, Alt, Shift или Win. Сочетание сохраняется и применяется
сразу. Если оно занято другим приложением, DxTools покажет его как
«Недоступна».

С Phase 2F используется низкоуровневый keyboard hook: работают сочетания с
Win, а совпавшие комбинации подавляются до обработки другими приложениями.

### Цепочки

Нажмите «Префикс» и задайте первую комбинацию. Затем основное сочетание
выполняется после префикса в течение 1,5 секунды. Пример: `Ctrl+Alt+F9`,
затем `Ctrl+Alt+F10`.

Кнопка «Сбросить префикс» возвращает одиночное сочетание. Поддерживаются
двухшаговые цепочки.

## 8. Обои

Вкладка «Обои» задаёт изображение для каждого монитора.

1. Нажмите «Выбрать изображение» у нужного монитора.
2. Выберите PNG, JPG, JPEG или BMP.
3. Повторите для остальных мониторов.
4. Выберите режим: «Заполнить», «Вписать», «Растянуть», «По центру»
   или «Замостить».
5. Нажмите «Применить обои».

DxTools создаёт композитное изображение размером с виртуальный рабочий стол
и устанавливает его в режиме span. Файлы композита находятся в
`%LocalAppData%\DxTools\wallpaper`. Старые композиты автоматически удаляются.

Если для монитора не выбрано изображение, его область будет чёрной.

### Слайдшоу

1. Нажмите «Выбрать папку» и укажите каталог с изображениями.
2. Задайте интервал в секундах.
3. Нажмите «Запустить слайдшоу».
4. Для остановки нажмите «Остановить».

Каждый тик выбирает следующее изображение для каждого монитора. Если папка
задана, кнопка «Применить обои» также запускает слайдшоу. Поддерживаются
PNG, JPG, JPEG и BMP.

## 9. Диагностика

- **Состояние native-библиотеки** — версия API, версия библиотеки и результат
  проверки связи.
- **Открыть папку логов** — `%LocalAppData%\DxTools\logs`.
- **Выполнить самопроверку** — повторно проверяет native-библиотеку.

## 10. Трей

Меню значка:

- **Открыть DxTools** — показать окно настроек;
- **Состояние** — краткая информация о native-модуле;
- **О программе** — версия и лицензия;
- **Выход** — завершить приложение.

## 11. Безопасный режим

Если приложение работает нестабильно, запустите:

```powershell
DxTools.exe --safe-mode
```

В безопасном режиме отключаются нативные проверки, горячие клавиши,
панель задач и авто-применение профилей. Настройки, логи и просмотр
конфигурации работают.

## 12. Командная строка

| Параметр | Действие |
|---|---|
| `--autostart` | запуск при входе в систему, окно скрыто |
| `--safe-mode` | безопасный режим |
| `--show` | показать окно в уже запущенном экземпляре |
| `--exit` | корректно завершить уже запущенный экземпляр |
| `--apply-display <name\|id>` | применить профиль дисплея при старте |
| `--apply-window <name\|id>` | применить профиль позиций окон |
| `--apply-wallpaper` | применить настроенные обои/слайдшоу |
| `--version` | показать версию |
| `--help` | краткая справка |

Пример:

```powershell
DxTools.exe --exit
```

## 13. Логи

Логи находятся в `%LocalAppData%\DxTools\logs\DxTools-YYYYMMDD.log`.
При аварийном завершении приложение показывает путь к логу. Перед отправкой
отчёта об ошибке приложите последний файл лога.

## 14. Триггеры и C#-скрипты

Вкладка «Триггеры» выполняет действие при событии.

- **Событие:** запуск DxTools, изменение конфигурации дисплея, создание окна,
  запуск процесса.
- **Действие:** применить профиль дисплея, профиль окон, обои, запустить
  программу или C#-скрипт.
- **Условие по процессу:** для событий окна/процесса — подстрока имени
  процесса; пустое условие совпадает всегда.
- **Параметр:** имя/id профиля, путь к программе или имя `.csx`-файла.

Скрипты находятся в `%AppData%\DxTools\scripts`. Доступные глобальные методы:
`Monitors`, `ApplyDisplayProfile(name)`, `ApplyWindowProfile(name)`,
`ApplyWallpaper()`, `Run(file)`, `Log(message)`.

Скрипты выполняются с полными правами пользователя. Запускайте только
доверенный код.

## 15. Известные ограничения 0.14.0-alpha

- панель задач: нет системного трея;
- при аварийном завершении DxTools панель задач Windows на дополнительном
  мониторе может остаться скрытой; перезапустите DxTools или Explorer;
- отдельные панели задач для сплитов не резервируют рабочую область;
- зеркало трея показывает снимки иконок и обновляется раз в 2 секунды при
  открытом popup;
- цепочки длиннее двух шагов не поддерживаются;
- изменение DPI scaling через профиль не поддерживается;
- виртуальные десктопы, screensaver, аудио, shell extension, UIAccess,
  ARM64 и подпись — Phase 3B;
- профили иконок зависят от порядка иконок и настроек автоупорядочивания;
- elevated-приложения могут не перемещаться без UIAccess; модуль — Phase 3B;
- нет автоматического обновления;
- установщик не подписан; SmartScreen может показать предупреждение;
- ARM64 не поддерживается.

## 16. Удаление

«Параметры → Приложения → Установленные приложения → DxTools → Удалить».
Чтобы удалить и настройки, после удаления удалите папки:

```
%AppData%\DxTools
%LocalAppData%\DxTools
```
