# Отчёт 1.0.0-rc.8 — hotkeys, контекстные меню трея, заставка

Дата: 2026-11-22.
Статус: **готово, ожидает review и публикации GA**.

## 1. Реализовано

### Горячие клавиши

- `HotkeySetting` хранит последовательность `HotkeyStep` (до четырёх шагов) и
  необязательную область действия `TargetProcess`.
- Старые настройки с `prefix + основное сочетание` автоматически мигрируют в
  `Steps` при загрузке; схема настроек — 11.
- Native API v6:
  - `DxTools_HotkeyBinding` содержит `stepCount`, `steps[4]`, `scope` и
    `processName[64]`;
  - hook поддерживает общие префиксы и последовательности любой длины до 4;
  - при привязке к приложению foreground-процесс проверяется через
    `QueryFullProcessImageNameW` с кэшем 250 мс;
  - клавиша не подавляется, если ни один кандидат не совпал.
- Редактор: пошаговый захват, `Enter` — завершить, `Backspace` — удалить шаг,
  до четырёх шагов, проверка дублей.
- Отдельный диалог выбора приложения: список процессов, ручной ввод,
  «Активное окно», «Любое приложение».
- Кнопки строки hotkey: «Изменить», «Приложение…», «Сбросить».

### Контекстные меню трея

- Правый клик по иконке в зеркале трея закрывает popup и открывает штатное
  контекстное меню этой иконки.
- Левая кнопка по-прежнему использует UIA `InvokePattern` с fallback на
  синтетический клик.

### Заставка

- `ScreensaverCommandLine` разбирает `/s`, `/c`, `/c:<HWND>`, `/p <HWND>` и
  `/p:<HWND>`; некорректный HWND приводит к тихому завершению.
- `/p` создаёт дочернее окно `HwndSource` внутри HWND панели управления,
  отслеживает размер и закрытие родителя.
- Видео из папки слайдшоу воспроизводится без звука через `MediaElement`;
  переход к следующему элементу по `MediaEnded`; при ошибке файл пропускается.
- Настройка `wallpaper.screensaverIncludeVideos` и чекбокс на вкладке «Обои».
- Полноэкранный режим и `/c` сохранены.

## 3. Ограничения

- Привязка к приложению определяется по имени процесса; для UWP и
  elevated-приложений определение может быть недоступно.
- Максимум четыре шага; более длинная цепочка имеет приоритет над короткой с
  тем же началом.
- Контекстное меню трея открывается синтетическим правым кликом по реальной
  иконке, поэтому курсор переводится на основную панель.
- Видео зависит от кодеков Media Foundation; неподдерживаемые файлы
  пропускаются.
- Подпись, ARM64 hardware и ручная матрица DPI/HDR/RDP не выполняются по
  решению заказчика.

## 4. Исправлено по ходу проверки

- Single-file `.scr` падал с `DllNotFoundException` при создании WPF-окна.
  В `DxTools.Screensaver.csproj` добавлено
  `IncludeNativeLibrariesForSelfExtract=true`; после этого `/p` и `/s`
  запускаются из опубликованного артефакта.
