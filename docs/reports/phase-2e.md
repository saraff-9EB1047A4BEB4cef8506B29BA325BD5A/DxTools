## 1. Что сделано

### Триггеры

- события: запуск DxTools, изменение конфигурации дисплея, создание окна,
  запуск процесса;
- условия по имени процесса для окон/процессов;
- действия: применить профиль дисплея, профиль окон, обои, запустить
  программу, запустить C#-скрипт;
- хранение в `%AppData%\DxTools\triggers.json` с атомарной записью;
- polling новых окон/процессов раз в 2 секунды;
- вкладка «Триггеры» с редактированием события, действия, условия и параметра;
- переключение enabled без перезапуска.

### C#-скрипты

- папка `%AppData%\DxTools\scripts`;
- выполнение `.csx` через Roslyn Scripting;
- глобальные методы: `Monitors`, `ApplyDisplayProfile(name)`,
  `ApplyWindowProfile(name)`, `ApplyWallpaper()`, `Run(file)`, `Log(message)`;
- кнопка открытия папки скриптов;
- проверено: startup-скрипт записал файл и сообщение в лог.

### Документация и поставка

## 3. Ограничения и отклонения

1. **Системный трей, titlebar-кнопки, сплиты, LL-hook/цепочки** не
   реализованы — Phase 2F/3.
2. Триггер `ApplyWallpaper` применяет статические `MonitorImages`; если задана
   только папка слайдшоу, действие не запускает слайдшоу.
3. Новые окна/процессы обнаруживаются polling-ом с задержкой до 2 секунд.
4. Условие поддерживает только подстроку имени процесса.
5. C#-скрипты выполняются с полными правами пользователя; доверяйте только
   своим скриптам.
6. Триггеры отключены в `--safe-mode`.
7. Mixed DPI не проверен; MSI не подписан; полная установка с UAC не
   выполнялась.
