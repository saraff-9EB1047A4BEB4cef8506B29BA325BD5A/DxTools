## 1. Что сделано

### DWM live-превью

- при наведении на кнопку группы панели задач открывается topmost-окно
  предпросмотра;
- используется `DwmRegisterThumbnail` + `DwmUpdateThumbnailProperties`
  для активного окна группы;
- отдельное native-окно `STATIC` с `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`,
  не перехватывает фокус;
- превью скрывается при уходе курсора, fullscreen и закрытии панели;
- для свёрнутых окон превью не открывается.

### Автоскрытие панели задач

- настройка «Автоскрытие панели задач» в разделе «Общие»;
- таймер 250 мс отслеживает курсор;
- уход курсора скрывает панель; подведение к нижнему краю показывает;
- при использовании AppBar он снимается на время скрытия (рабочая область
  расширяется) и регистрируется снова при показе;
- автоскрытие применяется без перезапуска через пересборку панелей;
- fullscreen-скрытие совместимо с автоскрытием.

### Сохранено из предыдущих фаз

- pinned apps, группировка, профили окон, редактор hotkeys, CLI;
- 23 unit-теста, MSI 0.6.0.

## 3. Ограничения и отклонения

1. **Системный трей не реализован** — Phase 2E/3.
2. **Titlebar-кнопки, триггеры, C#-скрипты, сплиты** не реализованы —
   Phase 2E/3.
3. **LL-hook и цепочки** не реализованы; hotkeys через `RegisterHotKey`.
4. DWM-превью показывает только активное/первое окно группы, не сетку
   всех окон.
5. При замене панели Windows (`Shell_SecondaryTrayWnd`) рабочая область
   остаётся зарезервированной при скрытии; это ограничение ветки замены.
6. Автоскрытие на AppBar-ветке не проверено на мониторе без панели Windows.
7. При аварийном kill панель Windows может остаться скрытой.
8. Mixed DPI не проверен на железе; MSI не подписан; полная установка с UAC
   не выполнялась.
