## 1. Что сделано

### Панель задач

- группировка окон по исполняемому файлу; кнопка группы показывает
  количество окон `(N)`;
- щелчок по группе переключает окна по кругу, одиночное окно
  активируется/сворачивается;
- обновлённая ширина/подписи и accessibility name;
- автоматическое скрытие панели, когда foreground-окно занимает весь
  монитор (fullscreen);
- сохранены AppBar, замена `Shell_SecondaryTrayWnd`, часы, прокрутка,
  восстановление панели Windows при выходе и `ProcessExit`.

### Профили окон

- вкладка «Окна» показывает текущие top-level окна, процесс, монитор и
  геометрию;
- сохранение позиций всех окон в профиль;
- применение профиля: сопоставление по exe + заголовку, затем по exe;
- восстановление развёрнутых/свёрнутых окон;
- удаление профилей;
- store `%AppData%\DxTools\window-profiles.json` с атомарной записью.

### Редактор горячих клавиш

- сочетания хранятся в `settings.json` (`HotkeySetting`);
- диалог захвата: требует модификатор, показывает новое сочетание;
- после изменения выполняется перерегистрация `RegisterHotKey`;
- список показывает активность/недоступность и кнопку «Изменить»;
- схема настроек обновлена до v4 с миграцией defaults.

- 21 unit-тест;
- MSI 0.4.0;

## 3. Ограничения и отклонения

1. Группировка выполняется по пути exe, а не по AUMID; UWP-приложения могут
   группироваться некорректно.
2. Fullscreen-скрытие реализовано, но не проверено на реальном fullscreen-
   приложении в этой сессии.
3. Нет pinned apps, системного трея, DWM live-превью и auto-hide.
4. Titlebar-кнопки, триггеры, C#-скрипты, сплиты и CLI-применение профилей —
   Phase 2C.
5. LL-hook и многошаговые цепочки не реализованы; остаётся `RegisterHotKey`,
   поэтому часть зарезервированных сочетаний недоступна.
6. Профили окон применяются только к уже открытым окнам; автоматическое
   восстановление при появлении новых окон не реализовано.
7. При аварийном kill панель Windows может остаться скрытой до перезапуска
   DxTools/Explorer.
8. Mixed DPI не проверен на железе (оба монитора 96 DPI).
9. Полная установка MSI с UAC не выполнялась; проверена административная
   установка. MSI не подписан.
