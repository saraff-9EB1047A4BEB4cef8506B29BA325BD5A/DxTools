## 1. Что сделано

### Зеркало системного трея

- кнопка «▾» на панели задач;
- UIA-сканирование области уведомлений Windows (`Shell_TrayWnd`);
- фильтрация иконок по правой области панели, исключение «Показать рабочий стол»;
- снимки иконок через `CopyFromScreen`, кэширование в `ImageSource`;
- popup с иконками и tooltip-именами;
- передача клика исходному элементу через UIA `InvokePattern`, fallback —
  клик по координатам через `mouse_event`;
- popup закрывается после выбора и обновляется при каждом открытии.

### Сохранено из предыдущих фаз

- сплиты, двухшаговые hotkey-цепочки, titlebar-overlay, LL-hook,
  панель задач, DWM-превью, автоскрытие, профили, триггеры, скрипты, CLI;
- 25 unit-тестов, MSI 0.12.0.

## 3. Ограничения и отклонения

1. **Отдельные панели задач для сплитов** не реализованы — Phase 2K/3.
2. Трей обновляется только при открытии popup, не live.
3. Нет контекстных меню трея; клик передаётся исходному элементу.
4. Снимки иконок могут захватывать фон/масштаб панели.
5. Mixed DPI не проверен; MSI не подписан; полная установка с UAC не
   выполнялась.
