## 1. Что сделано

### Закреплённые приложения

- список pinned apps в `settings.json` (схема v5);
- добавление `.exe` через диалог и удаление из раздела «Общие»;
- кнопки pinned apps на каждой панели задач DxTools;
- если приложение запущено, pinned-кнопка заменяется группой его окон;
- запуск приложения с панели задач при отсутствии окна;
- событие изменения pinned apps пересобирает панели без перезапуска.

### CLI-применение

- `--apply-display <name|id>` — применить профиль дисплея при старте;
- `--apply-window <name|id>` — применить профиль позиций окон;
- `--apply-wallpaper` — применить настроенные обои/слайдшоу;
- поиск по точному имени или id, поддержка `--option=value`;
- результаты пишутся в лог, ошибки не блокируют запуск.

### Сохранено из предыдущих фаз

- группировка окон, fullscreen-скрытие, AppBar, замена панели Windows;
- профили позиций окон, редактор hotkeys, слайдшоу обоев;
- 23 unit-теста, MSI 0.5.0.

## 3. Ограничения и отклонения

1. **DWM live-превью, системный трей, auto-hide** не реализованы —
   Phase 2D/3.
2. **Titlebar-кнопки, триггеры, C#-скрипты, сплиты** не реализованы —
   Phase 2D/3.
3. **LL-hook и многошаговые цепочки** не реализованы; используется
   `RegisterHotKey`.
4. Pinned apps добавляются вручную; импорт из закреплённых Windows нет.
5. Pinned apps отображаются на всех панелях, без привязки к монитору.
6. CLI-применение выполняется только при старте и только если другой
   экземпляр DxTools не запущен (single instance).
7. Fullscreen-скрытие панели не проверено на реальном fullscreen-приложении.
8. При аварийном kill панель Windows может остаться скрытой до перезапуска
   DxTools/Explorer.
9. Mixed DPI не проверен на железе; MSI не подписан; полная установка с UAC
   не выполнялась.
