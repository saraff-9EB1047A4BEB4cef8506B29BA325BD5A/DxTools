## 3. Ограничения и отклонения

1. Split taskbars — overlay без AppBar; рабочая область не резервируется,
   панели могут перекрывать нижнюю часть окон ячейки.
2. На каждой ячейке дублируются Dx-кнопка и часы; настройка состава не
   реализована.
3. Сплиты и split taskbars создаются только для неосновных мониторов.
4. Трей обновляется снимками, не live-иконками; контекстные меню не
   реализованы.
5. Mixed DPI не проверен; MSI не подписан; полная установка с UAC не
   выполнялась.
