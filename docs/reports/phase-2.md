## 1. Что сделано

### Панель задач на дополнительных мониторах

- WPF-панель высотой 48 DIP на каждом неосновном мониторе;
- AppBar: резервирование рабочего стола, корректная работа развёрнутых окон;
- если Windows уже показывает панель задач на этом мониторе, DxTools временно
  скрывает `Shell_SecondaryTrayWnd` и занимает её место;
- при нормальном выходе и `ProcessExit` панель задач Windows восстанавливается;
- кнопки окон с иконками процессов, активация и сворачивание по клику;
- индикация активного окна, часы, горизонтальная прокрутка списка;
- обновление списка окон раз в секунду, кэш иконок;
- настройка включения/выключения без перезапуска;
- primary taskbar Windows не изменяется.

### Слайдшоу обоев

- выбор папки с PNG/JPG/JPEG/BMP;
- настраиваемый интервал в секундах;
- циклическая смена изображений для каждого монитора;
- запуск/остановка, очистка папки;
- «Применить обои» при заданной папке запускает слайдшоу;
- сохранение настроек в `settings.json`.

### CLI/IPC

- `--exit` отправляет команду работающему экземпляру и корректно завершает
  его через named pipe;
- при выходе освобождаются AppBar, скрытые панели Windows и таймеры.

### Версия и поставка

- приложение 0.3.0-alpha.1, native DLL 0.3.0;
- MSI 0.3.0 с лицензионным диалогом, LICENSE и THIRD-PARTY-NOTICES;
- 19 unit-тестов;
- обновлены README, USER_MANUAL, spec, architecture, CHANGELOG;
- скриншоты панели задач и слайдшоу.

## 3. Ограничения и отклонения

1. **Phase 2 выполнена как ядро.** В Phase 2B перенесены: группировка окон,
   pinned apps, трей, DWM-превью, auto-hide, fullscreen-скрытие.
2. **Titlebar-кнопки, профили позиций окон, триггеры, C#-скрипты, сплиты**
   не реализованы — Phase 2B.
3. **LL-hook, цепочки и редактор горячих клавиш** не реализованы; остаются
   фиксированные `Ctrl+Alt+Left/Right/Up` на `RegisterHotKey`.
4. **Зеркалирование системного трея** не реализовано (2B, UIA go/no-go).
5. При аварийном завершении DxTools (Task Manager / kill) скрытая панель
   Windows может остаться скрытой до перезапуска DxTools/Explorer.
6. Панель задач зависит от класса `Shell_SecondaryTrayWnd`; смена внутреннего
   устройства Windows 11 может потребовать адаптации.
7. Fullscreen-приложения не скрывают панель автоматически.
8. Mixed DPI не проверен на железе (оба монитора 96 DPI).
9. Полная установка MSI с UAC не выполнялась; проверена административная
   установка. MSI не подписан.
10. Слайдшоу использует только верхний уровень папки.
