# Security review — DxTools 1.0.0-rc.1/rc.2

Дата: 2026-11-20 (в rc.2 код приложения не менялся)

## Область проверки

- загрузка native DLL и C ABI;
- глобальные хуки клавиатуры и WinEvent;
- cross-process доступ к Explorer (иконки рабочего стола);
- UIA-доступ к области уведомлений;
- пользовательские C#-скрипты;
- настройки, профили и логи;
- MSI и автозапуск;
- зависимости и лицензии.

## Результаты

| Проверка | Результат |
|---|---|
| Секреты в репозитории | `.env` в `.gitignore`, токен не коммитится |
| Сетевые подключения | нет исходящих соединений, кроме открытия URL пользователем |
| Телеметрия | отсутствует |
| Native DLL | загружается только из каталога приложения |
| Хуки | только `WH_KEYBOARD_LL` и WinEvent, без инъекций |
| Cross-process | Explorer desktop icon list, только текущий пользователь |
| Скрипты | выполняются с правами пользователя; предупреждение в UI/документации |
| Логи | локальные, без секретов; путь документирован |
| Safe mode | отключает хуки, taskbar, триггеры, аудио и native-проверки |
| MSI | per-machine, Program Files, без службы и драйвера |
| Автозапуск | HKCU Run, per-user |
| Зависимости | проверены на GPLv2-совместимость (MIT/BSD/ISC) |
| Подпись | скрипт есть, сертификат не настроен |

## Открытые вопросы

1. Release-бинарники не подписаны; SmartScreen может предупреждать.
2. UIAccess/elevated helper не реализован.
3. Shell context menu не реализован.
4. ARM64 не собран и не проверен.
5. Нет независимого пентеста; рекомендуется перед GA.
6. `IPolicyConfig` и UIA-зеркало трея зависят от внутренних API Windows.

## Рекомендации перед GA

- приобрести OV/EV сертификат и подписывать exe/dll/msi;
- провести аудит native-кода и fuzzing C ABI;
- проверить MSI на чистой VM с UAC;
- протестировать на Windows 11 23H2/24H2/25H2 и ARM64;
- ограничить выполнение скриптов предупреждением и журналом.
